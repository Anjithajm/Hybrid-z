Installation
============

Prerequisites
-------------
- Python 3.7 or higher

Install from repository
-----------------------

1. Clone the repository:

.. code-block:: bash

   git clone https://github.com/Anjithajm/Hybrid-z.git
   cd Hybrid-z

2. Install dependencies:

.. code-block:: bash

   pip install -r requirements.txt

Dependencies
------------

The main dependencies are:

*TensorFlow 2.19.0
* NumPy 2.1.3
* Pandas 2.2.3
* Astropy 7.0.1
* scikit-learn 1.6.1
* Matplotlib 3.10.0
