Citing Hybrid-z
===============

Hybrid-z was developed for the **Kilo-Degree Survey (KiDS) DR4 Bright Sample** and has been
extended to the **KiDS DR4 Quasar** sample.

If you use Hybrid-z in your research, please cite the following publications:

- **KiDS DR4 Bright Sample**:  
`A&A 2025 publication <https://www.aanda.org/articles/aa/full_html/2025/06/aa53576-24/aa53576-24.html>`_

- **KiDS DR4 Quasars**:  
  `arXiv:2511.17311 <https://arxiv.org/abs/2511.17311>`_
